

UFRRJ — Projeto de Extensão
Site estático desenvolvido com HTML5, CSS3 e JavaScript Vanilla para a apresentação de projetos de extensão.

 Como Executar:
Basta abrir o arquivo index.html diretamente no seu navegador ou rodar um servidor local na pasta do projeto:

Bash
# Usando Python
python3 -m http.server 8080


📂 Estrutura do Projeto
index.html: Página inicial.

sobre.
html: Informações sobre a atividade.

atividades.html: Equipe e liderança.

contato.html: FAQ e canais de contato.

styles.css: Estilos gerais.

script.js: Lógica de interatividade (menu, FAQ, etc.).

🛠️ Padrões e Tecnologias
HTML: Uso de tags semânticas do HTML5 e práticas de acessibilidade (atributos aria-*).

CSS: Padrão BEM (Block Element Modifier), design mobile-first e variáveis de ambiente no :root.

JavaScript: Vanilla moderno (ES6+), sem bibliotecas, responsável pela interatividade do menu mobile e accordion do FAQ.
