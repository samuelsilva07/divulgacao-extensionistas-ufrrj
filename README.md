# 🔎 Divulgação dos Impactos das Atividades Extensionistas do Departamento de Ciência da Computação 

Está página web foi desenvolvido por alunos da Universidade Federal Rural do Rio de Janeiro **(UFRRJ)** para o projeto de Divulgação e Popularização da Ciência da Computação, para exibir a análise dos resultados das atividades extensionistas promovidas pelo Departamento de Ciência da Computação **(DCC)**, com o objetivo de direcionar o trabalho dos futuros projetos promovidos pelo curso e entender o impacto gerado pelos estudantes na comunidade.

## 🗒️ Etapas do projeto

### 🧪 Coleta de dados: 

Realização de pesquisa com os professores do DCC e com escolas do município de Nova Iguaçu, para obter informações como:
 
- Quantidade de participantes 
- Público alvo atingido 
- Principais obstáculos para a inserção da tecnologia no ensino básico 
- Projetos de interesse relacionados a tecnologia

### 📈 Tratamento de dados e geração de dashboards

Após a realização da pesquisa, foi necessário um tratamento dos dados obtidos, para em seguida iniciar a construção dos dashboards, essenciais para exibir os resultados obtidos de forma clara e direta. Os dashboards foram produzidos para duas categorias:

- Pesquisas realizadas com escolas, apresentando as demandas e interesses mais frequentes delas em relação às diversas áreas da computação 
- Pesquisa com professores, buscando mostrar o resultado e impacto das atividades coordenadas por cada um

### 🛠️ Construção do site

Para sintetizar os resultados dos processos anteriores, uma página web foi produzida para informar o objetivo do trabalho realizado e apresentar os dados/dashboards obtidos através das pesquisas, assim como divulgar os programas realizados por cada atividade extensionista.


## 💻 Tecnologias utilizadas

- **Tratamento de dados**: Python, Pandas
- **Página web**: HTML, CSS e Java Script
